📌 What is Figma?

Figma is a cloud-based design and prototyping platform used to create websites, mobile applications, interfaces, wireframes, prototypes, and complete design systems.

Its collaborative workflow allows multiple people to work on the same design file, leave comments, review changes, and share components and libraries across projects.
